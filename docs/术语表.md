## 📖 术语定义

| 中文术语 | 英文术语 | 定义 | 示例/备注 |
|----------|----------|------|-----------|
| **标准价** | Standard Price/Std | 当前正常的采购成本或生产成本 | 对应数据库 `std_price` |
| **BOM** | Bill of Materials | 物料清单，产品所需材料的明细列表 | 通常以 Excel 格式上传 |
| **MHR** | Machine Hour Rate | 机时费率，每小时机器运行的综合成本 | v1.5 对齐 VOSS 标准：MHR = var + fix；分母 = (净小时数 + 调试时间)；负载系数固定 0.78 |
| **MHR_var** | Machine Hour Rate Variable | 机时变动费率（与产量相关） | v1.7 能源公式：`(每小时能耗÷机器数量)×总工时×能源单价(0.78)`；含刀具、耗材、维护、其他变动成本 |
| **MHR_fix** | Machine Hour Rate Fixed | 机时固定费率（与产量无关） | v1.5 折旧公式：`设备原值/折旧年限×机器数`；含利息、租金、保险等 |
| **机器数** | Machine Count | 同类型设备数量 | v1.5 新增：用于折旧计算 |
| **调试时间** | Set-up Hours | 调试/换型时间 | v1.5 新增：MHR 分母组成部分 |
| **负载系数** | Load Factor | 实际功率与额定功率比率 | v1.5 更新：固定值 0.78（VOSS 标准） |
| **摊销模式** | Amortization Mode | 投资/研发成本的摊销策略 | total_volume_based（全生命周期）/ fixed_3_years（前3年） |
| **QS** | Quote Summary | 报价摘要，客户视角的报价总览 | 含总金额、利润率、交期等 |
| **BC** | Breakdown | 成本分解，内部视角的成本结构透明化 | 分为物料成本、工艺成本 |
| **项目总体需求量** | Project Volume | 🔴 v1.6 泛化：客户项目的年度总体需求量 | 用于计算零件销量：`销量 = 项目总体需求量 × 单套用量`；适配储能、数据中心等通用制造行业 |
| **单套用量** | Usage per System | 🔴 v1.6 泛化：每套系统/平台的零件用量 | 如 0.15 件/套；替代原"单车用量" |
| **HK III** | Herstellkosten III | 制造成本（工厂大门成本） | 不含研发和模具分摊 |
| **SK-1** | Selbstkosten I | 项目综合成本（不含分摊） | `HK III + 管销费用(S&A)` |
| **SK-2** | Selbstkosten II | 项目全成本（含所有分摊与附加） | `SK-1 + 摊销 + SAP + 物流 + 寄售库存 + ...` |
| **SK** | Selbstkosten | 完全成本（同 SK-2） | 德系成本核算术语；本文档中 SK 默认指 SK-2 |
| **DB I** | Deckungsbeitrag I | 边际贡献 I（生产毛利） | `Net Sales - HK III` |
| **DB IV** | Deckungsbeitrag IV | 净利润，扣除所有投入后的最终利润 | `Net Sales - SK` |
| **目标 DB4** | Target DB4 | Sales 设定的目标净利润率 | 用于反推最低可接受单价 |
| **SAP 附加费** | SAP Surcharge | SAP 系统运营附加费 | `HK_III × sap_surcharge_rate`，通常 0.5% 🆕 v1.6 |
| **物流费** | Logistics | 物流包装费用 | `VP × logistics_rate` 🆕 v1.6 |
| **寄售库存** | Consign. Stock / VMI | 寄售库存/VMI 成本 | `VP × consign_stock_rate`，通常 2% 🆕 v1.6 |
| **反向定价** | Reverse Pricing | 根据目标利润率反推基准单价 | `VP = (SK-1+模具+SAP+R&D) ÷ (1-各项比例-DB4)` 🆕 v1.6 |
| **组合报价** | Package Quoting | 多产品组合报价模式 | 汇总多个产品的成本与财务指标 |
| **摊销分组** | Amortization Group | 多投资项分组独立摊销 | 如 Tooling 1、Tooling 2 各自独立摊销 |
| **NRE** | Non-Recurring Engineering | 一次性工程费用（模具、检具、研发投入） | 需按一定期限摊销 |
| **Payback** | Payback Period | 投资回收期，客户收回投资成本所需时间 | 以月为单位 |
| **SOP** | Start of Production | 量产启动时间 | 汽车行业常用术语 |
| **VM** | Value Management | 价值管理部门，报价流程的核心协调者 | 也称项目经理 |
| **IE** | Industrial Engineering | 工业工程部门，工艺路线维护者 | 负责工时预估 |
| **S&A** | Sales & Administration | 销售与管理费用，管销费用率 | 通常为销售额的 2-3% |
| **年降** | Sales Reduction / LTA | 客户要求的年度价格下降 | 包含三个参数：比例（3%-5%）、年限（2-3年）、开始年份（通常第二年） |
| **节拍工时** | Cycle Time | 完成单件产品所需的生产时长 | 以秒为单位 |
| **稼动率** | Efficiency Rate | 考虑设备故障、换模等因素后的实际产出率 | 通常为 75%-85% |
| **红绿灯** | Traffic Light Status | 数据置信度标识：🟢绿色(精确)、🟡黄色(估算)、🔴红色(缺失) | 用于审核优先级 |

## 🎨 状态颜色系统

| 颜色 | 含义 | 条件 | 操作建议 |
|------|------|------|----------|
| 🟢 Green | 自动通过 | 物料号完全匹配且价格有效 | 可直接使用 |
| 🟡 Yellow | 人工复核 | AI 语义匹配或 AI 估算参数 | 需确认后使用 |
| 🔴 Red | 人工介入 | 库中无数据且 AI 无法匹配 | 必须人工询价 |

## 📊 成本层级结构

```
Total Price (报价)
├── SK-2 (项目全成本) ────────────────────────────────────────┐
│   ├── SK-1 (项目综合成本)                                   │
│   │   ├── HK III (制造成本)                                 │
│   │   │   ├── Material Cost (物料成本)                      │
│   │   │   │   ├── Raw Materials (原材料)                    │
│   │   │   │   └── Purchased Parts (外购件)                  │
│   │   │   └── Process Cost (工艺成本)                       │
│   │   │       ├── Machine Cost (MHR × Cycle Time)           │
│   │   │       ├── Labor Cost (人工成本)                     │
│   │   │       ├── Logistics (物流包装费)                    │
│   │   │       └── Other Mfg (其他制造费用)                  │
│   │   └── S&A (管销费用，~2.1%)                             │
│   ├── Tooling Amortization (模具摊销)                       │
│   │   ├── Tooling 1 (主模具分组)                            │
│   │   └── Tooling 2 (副模具分组) 🆕                         │
│   ├── R&D Amortization (研发摊销)                           │
│   ├── SAP Surcharge (SAP 系统附加费) 🆕                      │
│   ├── Consign. Stock (寄售库存/VMI 成本) 🆕                  │
│   └── Payment Interest (账期利息)                           │
└── Margin (利润 / DB4)                                       │
                                                              │
──────────────────────────────────────────────────────────────┘
注：🆕 标记为 v1.4 新增成本项
```
