## 1. 成本累加逻辑 (Cost Build-up)

这部分展示了成本是如何像"叠罗汉"一样一层层加上去的。系统将成本严格分为 `HK III`、`SK-1` 和 `SK-2` 三个层级，以确保数据边界清晰。

### 1.1 成本层级公式定义

| 层级 | 成本项 | 公式 | 业务含义 |
|------|--------|------|----------|
| **基础** | **HK III** | = Material_Cost + Production_Cost | 制造成本（工厂大门成本） |
| **一级** | **SK-1** | = HK_III × (1 + S&A_Rate) | 综合成本（含基础管销费用）|
| **附加** | Tooling Amort 1..n | 取自 `amortization_strategies` 表的分摊值 | 各模具/投资项的分摊费用（已含资本利息） |
| **附加** | SAP Surcharge | = HK_III × SAP_Surcharge_Rate | SAP 系统附加费 |
| **附加** | Logistics | = HK_III × Logistics_Rate | 物流包装费 |
| **附加** | R&D Validation | 取自 R&D 投资分摊计算 | 研发验证分摊费 |
| **附加** | Interest Payment | = VP × Interest_Rate × (Payment_Days / 360) | 营运资金利息（资金占用成本） |
| **附加** | Consign. Stock | = HK_III × Consign_Stock_Rate | 寄售库存/VMI 成本 |
| **二级** | **SK-2** | = SK-1 + ∑Tooling + SAP + Logistics + R&D + Interest + Consign | 项目全成本 (Project Full Cost) |

**SK-2 完整公式：**

$$SK\text{-}2 = SK\text{-}1 + \sum_{i=1}^{n} Tooling\_Amort_i + SAP\_Surcharge + Logistics + R\&D\_Amort + Interest_{Payment} + Consign\_Stock$$

> ⚠️ **核心架构原则：** 除"营运资金利息（Interest Payment）"外，所有费率项（SAP、物流、寄售等）的计算基数必须是 `HK III`，绝不能是销售单价 `VP`。这是打破循环引用（Circular Reference）地雷的关键。

### 1.2 多模具分组分摊

**业务场景：** 当项目存在多个不同设计寿命或归属的模具/夹具时，Sales 可以将它们分配到不同的 **Group** 进行独立分摊。

| 分组名称 | 适用场景 | 分摊策略 |
|----------|----------|----------|
| **Tooling 1** | 主模具（设计寿命 3 年） | 分摊 2 年 |
| **Tooling 2** | 辅助模具（设计寿命 5 年） | 分摊 3 年 |
| **Tooling 3** | 后期追加投资 | 按实际情况分摊 |

**详细计算逻辑：** 参考 [NRE投资成本计算逻辑.md](NRE投资成本计算逻辑.md)

## 2. 销售与利润逻辑 (Sales & Margin)

这部分定义了系统的核心考核指标体系。VOSS 财务采用多维监控指标来考核不同部门的绩效。

### 2.1 核心考核指标公式

| 考核维度 | 指标名称 | 公式 | 业务含义与用途 |
|----------|----------|------|----------------|
| **采购/工程** | GM% (材料毛利率) | = (VP - Material_Cost) / VP | 考核材料成本控制水平 |
| **工厂生产** | DB1 only based on HK3 | = (VP - HK_III) / VP | 生产毛利率，考核工厂的直接制造效率 |
| **项目综合** | DB1 considering all costs | = (VP - SK-1) / VP | 项目综合毛利，考虑了管销费用，用于考核项目的基本盈利能力 |
| **最终底线** | **DB4 (净利率)** | = (VP - SK-2) / VP | 最终净利率，最关键的审批指标，决定项目最终是否赚钱 |
| **绝对值** | DB4 Value | = DB4 × 销量 | 净利总额，直观反映项目带来的现金流 |

### 2.2 指标层级关系

```
GM% (材料毛利率)
  ↓ 扣除生产成本
DB1 based on HK3 (生产毛利率)
  ↓ 扣除管销费用
DB1 considering all (项目综合毛利)
  ↓ 扣除分摊与附加（Tooling + SAP + Logistics + R&D + Interest + Consign）
DB4 (净利率)
```

### 2.3 生命周期年降模型 (LTA)

报价不能只算静态的一年，必须结合汽车行业的年降要求生成完整的生命周期数据。

**VP 计算公式：**

$$VP_n = Base\_Price \times (1 - Total\_Reduction_n)$$

> *说明：* $Total\_Reduction_n$ 是基于首年单价的累计线性降幅（例如 3%, 6%, 9%）。

**输入参数需求：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| LTA_Rate | 年降比例 | 3% |
| LTA_Duration | 年降持续年限 | 3 年 |
| LTA_Start_Year | 从第几年开始执行年降 | 2（第二年） |

## 3. Dr.aiVOSS 系统开发规范

### 3.1 预警逻辑控制 (Warning Triggers)

系统必须对关键利润指标 `DB4` 实施颜色预警拦截，以辅助 Sales 和 Controlling 决策：

| 预警级别 | 条件 | UI 表现 | 处理机制 |
|----------|------|---------|----------|
| 🔴 **高风险** | DB4 < -5% | 红色背景 + ⚠️ 图标 | 强制要求 Sales 在提交审批时填写《战略意图说明》 |
| 🟡 **警告** | -5% ≤ DB4 < 0% | 黄色背景 | 提示亏损风险 |
| 🟢 **正常** | DB4 ≥ 0% | 绿色背景 | 正常通过 |

### 3.2 分摊策略配置

| 策略 | 说明 | 效果 |
|------|------|------|
| **Upfront (一次性支付)** | 客户单独付费，不计入零件单价 | Tooling 列为 0，第一年利润好看 |
| **Amortized (分摊进单价)** | 公司垫资开模，客户通过买零件分期还款 | Tooling 列有数值，前两年利润通常为负 |

### 3.3 年降计算引擎

**业务规则：**
- 第 1 年（SOP）：使用基准价格，无年降
- 第 N 年（N ≥ 开始年份 且 N < 开始年份 + 年降年限）：执行年降
- 第 N 年（N ≥ 开始年份 + 年降年限）：保持最后一年的价格

**Python 实现：**

```python
def calculate_price_with_lta(
    base_price: Decimal,
    lta_rate: Decimal,       # 年降比例，如 0.03
    lta_duration: int,       # 年降年限，如 3
    lta_start_year: int,     # 开始年份，如 2
    current_year: int        # 当前年份（相对于 SOP）
) -> Decimal:
    if current_year < lta_start_year:
        return base_price
    elif current_year < lta_start_year + lta_duration:
        years_of_reduction = current_year - lta_start_year + 1
        total_reduction = lta_rate * years_of_reduction
        return base_price * (1 - total_reduction)
    else:
        final_reduction = lta_rate * lta_duration
        return base_price * (1 - final_reduction)
```

## 5. 数据模型定义

### 5.1 QuotationYearData 单年度数据模型

```python
class QuotationYearData(BaseModel):
    """单年度报价数据"""
    year: int
    volume: int

    # 成本层级
    material_cost: Decimal       # Material Cost
    production_cost: Decimal     # Production Cost
    hk_3: Decimal                # HK III 制造成本
    sk_1: Decimal                # SK-1 综合成本（含管销）
    tooling_amort: Decimal       # Tooling 分摊（含 Capital Interest）
    sap_surcharge: Decimal       # SAP 系统附加费
    logistics: Decimal           # 物流费用
    rnd_amort: Decimal           # R&D 分摊
    interest_payment: Decimal    # 营运资金利息
    consign_stock: Decimal       # 寄售库存成本
    sk_2: Decimal                # SK-2 项目全成本

    # 销售与利润
    vp: Decimal                  # VP 销售单价
    db4_rate: Decimal            # DB4 净利率
    db4_value: Decimal           # DB4 净利总额

    # 预警
    is_warning: bool = False     # 是否预警 (DB4 < -5%)
```

### 5.2 计算公式汇总

```python
# 成本累加
hk_3 = material_cost + production_cost
sk_1 = hk_3 * (1 + sa_rate)  # S&A 管销费用

# 附加费用（基于 HK III，避免循环引用）
sap_surcharge = hk_3 * sap_surcharge_rate
logistics = hk_3 * logistics_rate
consign_stock = hk_3 * consign_stock_rate

# 营运资金利息（唯一基于 VP 的成本项）
interest_payment = vp * interest_rate * (payment_terms_days / 360)

# 项目全成本
sk_2 = sk_1 + tooling_amort + sap_surcharge + logistics + rnd_amort + interest_payment + consign_stock

# 净利率
db4_rate = (vp - sk_2) / vp
db4_value = db4_rate * volume
```

## 6. 计算流程图

```mermaid
flowchart TD
    A[开始] --> B[读取参数: Base Year, LTA Rate/Duration/StartYear, Strategy]
    B --> C{分摊策略?}
    C -->|Upfront| D[Tooling/R&D 单独开票]
    C -->|Amortized| E[计算分摊金额]
    D --> F[遍历每一年]
    E --> F
    F --> G[计算年降后 VP]
    G --> H[计算 HK3 = Material + Production]
    H --> I[计算 SK1 = HK3 × (1 + S&A_Rate)]
    I --> J[计算附加费用<br/>SAP/Logistics/Consign 基于 HK3]
    J --> K[计算 Interest = VP × Rate × Days/360]
    K --> L[计算 SK2 = SK1 + 附加 + Interest]
    L --> M[计算 DB4 = (VP - SK2) / VP]
    M --> N{DB4 < -5%?}
    N -->|是| O[标记预警 🔴]
    N -->|否| P[继续]
    O --> P
    P --> Q{还有年份?}
    Q -->|是| F
    Q -->|否| R[计算汇总指标]
    R --> S[输出 Quotation Summary]
    S --> T[结束]
```
