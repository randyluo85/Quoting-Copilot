## 1. 成本累加逻辑 (Cost Build-up)

这部分展示了成本是如何像"叠罗汉"一样一层层加上去的。系统将成本严格分为 `HK III`、`SK-1` 和 `SK-2` 三个层级，以确保数据边界清晰。

### 1.1 成本层级公式定义

| 层级 | 成本项 | 公式 | 业务含义 |
|------|--------|------|----------|
| **基础** | **HK III** | = Material_Cost + Production_Cost | 制造成本（工厂大门成本） |
| **一级** | **SK-1** | = HK_III × SG&A_Rate | 综合成本（含管销费用，SG&A_Rate 如 1.175）|
| **附加** | Tooling Amort 1..n | 取自 `amortization_strategies` 表的分摊值 | 各模具/投资项的分摊费用（已含资本利息） |
| **附加** | SAP Surcharge | = HK_III × SAP_Surcharge_Rate | SAP 系统附加费 |
| **附加** | Logistics | = HK_III × Logistics_Rate | 物流包装费 |
| **附加** | R&D Validation | 取自 R&D 投资分摊计算 | 研发验证分摊费 |
| **附加** | Interest Payment | = VP × Interest_Rate × (Payment_Days / 360) | 营运资金利息（资金占用成本） |
| **附加** | Consign. Stock | = HK_III × Consign_Stock_Rate | 寄售库存/VMI 成本 |
| **二级** | **SK-2** | = SK-1 + ∑Tooling + SAP + Logistics + R&D + Interest + Consign | 项目全成本 (Project Full Cost) |

**SK-2 完整公式：**

$$SK\text{-}2 = SK\text{-}1 + \sum_{i=1}^{n} Tooling\_Amort_i + SAP\_Surcharge + Logistics + R\&D\_Amort + Interest_{Payment} + Consign\_Stock$$

### 1.3 独立计算参数 🆕 v1.4

以下参数为**独立计算项**，不影响 SK 成本，用于管理层决策和报价参考：

| 参数 | 全称 | 说明 | 计算基数 | 默认值示例 |
|------|------|------|----------|------------|
| **MGK** | Materialgemeinkosten / Indirect Material Costs | 间接材料成本（采购、存储、运输等） | HK_III × MGK_Rate | 4% (系数 1.04) |
| **FGK** | Fertigungsgemeinkosten / Indirect Production Costs | 间接生产成本（生产管理、设备折旧、工厂运营等） | HK_III × FGK_Rate | 27.7% (系数 1.277) |
| **Risk** | Risk/Scrap Costs | 风险/废料成本（损耗、报废品、质量风险等） | HK_III × Risk_Rate | 3.5% (系数 1.035) |

**计算公式：**

```
# 间接材料成本
MGK_Cost = HK_III × (MGK_Rate - 1)

# 间接生产成本
FGK_Cost = HK_III × (FGK_Rate - 1)

# 风险/废料成本
Risk_Cost = HK_III × (Risk_Rate - 1)

# 或直接使用系数计算总附加
Total_Overhead = HK_III × (MGK_Rate + FGK_Rate + Risk_Rate - 3)
```

**数据来源：**
- 默认值：`business_case_params.{mgk_rate_base, fgk_rate_base, risk_rate_base}`
- 年度配置：`business_case_years.{mgk_rate, fgk_rate, risk_rate}`（为空时使用默认值）

> ⚠️ **核心架构原则：** 除"营运资金利息（Interest Payment）"外，所有费率项（SAP、物流、寄售等）的计算基数必须是 `HK III`，绝不能是销售单价 `VP`。这是打破循环引用（Circular Reference）地雷的关键。

### 1.2 多模具分组分摊

**业务场景：** 当项目存在多个不同设计寿命或归属的模具/夹具时，Sales 可以将它们分配到不同的 **Group** 进行独立分摊。

| 分组名称 | 适用场景 | 分摊策略 |
|----------|----------|----------|
| **Tooling 1** | 主模具（设计寿命 3 年） | 分摊 2 年 |
| **Tooling 2** | 辅助模具（设计寿命 5 年） | 分摊 3 年 |
| **Tooling 3** | 后期追加投资 | 按实际情况分摊 |

**详细计算逻辑：** 参考 [NRE投资成本计算逻辑.md](NRE投资成本计算逻辑.md)

## 2. 销售与利润逻辑 (Sales & Margin)

这部分定义了系统的核心考核指标体系。VOSS 财务采用多维监控指标来考核不同部门的绩效。

### 2.1 核心考核指标公式

| 考核维度 | 指标名称 | 公式 | 业务含义与用途 |
|----------|----------|------|----------------|
| **采购/工程** | GM% (材料毛利率) | = (VP - Material_Cost) / VP | 考核材料成本控制水平 |
| **采购/工程** | **GM in value** (毛利额) | = (VP - Material_Cost) × Volume = GM% × Sales Revenue | 材料毛利总额，用于评估采购端整体贡献 |
| **工厂生产** | DB1 only based on HK3 | = (VP - HK_III) / VP | 生产毛利率，考核工厂的直接制造效率 |
| **工厂生产** | **DB1 Value (HK3)** | = (VP - HK_III) × Volume = DB1_HK3 × Sales Revenue | 生产毛利总额 |
| **项目综合** | DB1 considering all costs | = (VP - HK3_Considering_all_costs) / VP | 项目综合毛利，考虑了管销费用，用于考核项目的基本盈利能力 |
| **项目综合** | **DB1 Value (all costs)** | = (VP - HK3_Considering_all_costs) × Volume | 项目综合毛利总额 |
| **最终底线** | **DB4 (净利率)** | = (VP - SK-2) / VP | 最终净利率，最关键的审批指标，决定项目最终是否赚钱 |
| **最终底线** | **DB4 Value** | = DB4 × Sales Revenue | 净利总额，直观反映项目带来的现金流 |

### 2.2 辅助指标与参数

| 指标名称 | 公式 | 业务含义 |
|----------|------|----------|
| **Sales Revenue** (营业额) | = VP × Volume | 年度销售总收入 |
| **HK$ Considering all costs** | = HK_III + SG&M_Portion + ∑Tooling + SAP + Logistics + R&D + Consign | 含管销和附加成本的项目成本（不含营运资金利息） |
| **Project Volume** (项目需求量) | 取自 `business_case_years.project_volume` | 项目/系统/平台年度总需求量 |
| **Usage per System** (单套用量) | 取自 `business_case_years.usage_per_system` | 每个项目/系统中该产品的用量 |
| **Productivity** (生产率) | = (Actual_Output / Planned_Capacity) × 100% | 产能利用率指标，反映生产效率水平 |

> **说明：** `HK$ Considering all costs` 与 `SK-2` 的区别在于：
> - `HK$ Considering all costs` 不包含营运资金利息（Interest Payment），反映项目本身的盈利能力
> - `SK-2` 包含所有成本包括营运资金利息，是完整的全成本

### 2.2 指标层级关系

```
GM% (材料毛利率)
  ↓ 扣除生产成本
DB1 based on HK3 (生产毛利率)
  ↓ 扣除管销费用
DB1 considering all (项目综合毛利)
  ↓ 扣除分摊与附加（Tooling + SAP + Logistics + R&D + Interest + Consign）
DB4 (净利率)
```

### 2.3 生命周期年降模型 (LTA)

报价不能只算静态的一年，必须结合汽车行业的年降要求生成完整的生命周期数据。

**VP 计算公式：**

$$VP_n = Base\_Price \times (1 - Total\_Reduction_n)$$

> *说明：* $Total\_Reduction_n$ 是基于首年单价的累计线性降幅（例如 3%, 6%, 9%）。

**输入参数需求：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| LTA_Rate | 年降比例 | 3% |
| LTA_Duration | 年降持续年限 | 3 年 |
| LTA_Start_Year | 从第几年开始执行年降 | 2（第二年） |

## 3. Dr.aiVOSS 系统开发规范

### 3.1 预警逻辑控制 (Warning Triggers)

系统必须对关键利润指标 `DB4` 实施颜色预警拦截，以辅助 Sales 和 Controlling 决策：

| 预警级别 | 条件 | UI 表现 | 处理机制 |
|----------|------|---------|----------|
| 🔴 **高风险** | DB4 < -5% | 红色背景 + ⚠️ 图标 | 强制要求 Sales 在提交审批时填写《战略意图说明》 |
| 🟡 **警告** | -5% ≤ DB4 < 0% | 黄色背景 | 提示亏损风险 |
| 🟢 **正常** | DB4 ≥ 0% | 绿色背景 | 正常通过 |

### 3.2 分摊策略配置

| 策略 | 说明 | 效果 |
|------|------|------|
| **Upfront (一次性支付)** | 客户单独付费，不计入零件单价 | Tooling 列为 0，第一年利润好看 |
| **Amortized (分摊进单价)** | 公司垫资开模，客户通过买零件分期还款 | Tooling 列有数值，前两年利润通常为负 |

### 3.3 年降计算引擎

**业务规则：**
- 第 1 年（SOP）：使用基准价格，无年降
- 第 N 年（N ≥ 开始年份 且 N < 开始年份 + 年降年限）：执行年降
- 第 N 年（N ≥ 开始年份 + 年降年限）：保持最后一年的价格

**Python 实现：**

```python
def calculate_price_with_lta(
    base_price: Decimal,
    lta_rate: Decimal,       # 年降比例，如 0.03
    lta_duration: int,       # 年降年限，如 3
    lta_start_year: int,     # 开始年份，如 2
    current_year: int        # 当前年份（相对于 SOP）
) -> Decimal:
    if current_year < lta_start_year:
        return base_price
    elif current_year < lta_start_year + lta_duration:
        years_of_reduction = current_year - lta_start_year + 1
        total_reduction = lta_rate * years_of_reduction
        return base_price * (1 - total_reduction)
    else:
        final_reduction = lta_rate * lta_duration
        return base_price * (1 - final_reduction)
```

## 5. 数据模型定义

### 5.1 QuotationYearData 单年度数据模型

```python
class QuotationYearData(BaseModel):
    """单年度报价数据（完整版）"""
    year: int
    volume: int

    # 基础信息
    article_number: str          # 产品/零件号
    product_description: str     # 产品描述
    project_volume: int          # 项目需求量（如储能系统年产量）
    usage_per_system: Decimal    # 单套用量（Factor per vehicle）
    productivity: Decimal        # 生产率/产能利用率

    # 成本层级
    material_cost: Decimal       # Material Cost
    production_cost: Decimal     # Production Cost
    hk_3: Decimal                # HK III 制造成本
    sk_1: Decimal                # SK-1 综合成本（含管销）
    tooling_amort_1: Decimal = Decimal("0")  # Tooling 1 分摊
    tooling_amort_2: Decimal = Decimal("0")  # Tooling 2 分摊（可选）
    sap_surcharge: Decimal       # SAP 系统附加费
    logistics: Decimal           # 物流费用
    rnd_amort: Decimal           # R&D 分摊
    interest_payment: Decimal    # 营运资金利息
    consign_stock: Decimal       # 寄售库存成本
    hk_considering_all: Decimal  # 含附加成本（不含利息）
    sk_2: Decimal                # SK-2 项目全成本（含利息）

    # 销售与利润
    vp: Decimal                  # VP 销售单价
    sales_revenue: Decimal       # 营业额 = VP × Volume

    # 利润指标（百分比）
    gm_rate: Decimal             # GM% 材料毛利率
    db1_hk3_rate: Decimal        # DB1 based on HK3 生产毛利率
    db1_all_rate: Decimal        # DB1 considering all costs 综合毛利率
    db4_rate: Decimal            # DB4 净利率

    # 利润指标（绝对值）
    gm_value: Decimal            # GM in value 材料毛利额
    db1_hk3_value: Decimal       # DB1 Value (HK3) 生产毛利额
    db1_all_value: Decimal       # DB1 Value (all costs) 综合毛利额
    db4_value: Decimal           # DB4 Value 净利总额

    # 预警
    is_warning: bool = False     # 是否预警 (DB4 < -5%)
```

### 5.2 计算公式汇总（完整版）

```python
# ============================================
# 基础信息计算
# ============================================
volume = project_volume * usage_per_system  # 销量 = 项目需求量 × 单套用量
productivity = (actual_output / planned_capacity) * 100  # 生产率

# ============================================
# 成本累加（自下而上）
# ============================================
hk_3 = material_cost + production_cost  # 制造成本

sga_portion = hk_3 * (sga_rate - 1)     # SG&A 附加部分
sk_1 = hk_3 * sga_rate                  # 综合成本（含管销）

# 附加费用（基于 HK III，避免循环引用）
tooling_amort_1 = get_tooling_amortization(tooling_1, volume, year)
tooling_amort_2 = get_tooling_amortization(tooling_2, volume, year)
sap_surcharge = hk_3 * sap_surcharge_rate
logistics = hk_3 * logistics_rate
rnd_amort = get_rnd_amortization(rnd_invest, volume, year)
consign_stock = hk_3 * consign_stock_rate

# 营运资金利息（唯一基于 VP 的成本项）
interest_payment = vp * interest_rate * (payment_terms_days / 360)

# 含附加成本（不含利息）
hk_considering_all = sk_1 + tooling_amort_1 + tooling_amort_2 + sap_surcharge + logistics + rnd_amort + consign_stock

# 项目全成本（含所有成本）
sk_2 = hk_considering_all + interest_payment

# ============================================
# 销售与利润计算
# ============================================
sales_revenue = vp * volume  # 营业额

# 利润指标（百分比）
gm_rate = (vp - material_cost) / vp  # 材料毛利率
db1_hk3_rate = (vp - hk_3) / vp  # 生产毛利率
db1_all_rate = (vp - hk_considering_all) / vp  # 综合毛利率
db4_rate = (vp - sk_2) / vp  # 净利率

# 利润指标（绝对值）
gm_value = gm_rate * sales_revenue  # 材料毛利额
db1_hk3_value = db1_hk3_rate * sales_revenue  # 生产毛利额
db1_all_value = db1_all_rate * sales_revenue  # 综合毛利额
db4_value = db4_rate * sales_revenue  # 净利总额

# ============================================
# 预警判断
# ============================================
is_warning = db4_rate < Decimal("-0.05")  # DB4 < -5% 预警
```

## 6. 计算流程图

```mermaid
flowchart TD
    A[开始] --> B[读取参数: Base Year, LTA Rate/Duration/StartYear, Strategy]
    B --> C{分摊策略?}
    C -->|Upfront| D[Tooling/R&D 单独开票]
    C -->|Amortized| E[计算分摊金额]
    D --> F[遍历每一年]
    E --> F
    F --> G[计算年降后 VP]
    G --> H[计算 HK3 = Material + Production]
    H --> I[计算 SK1 = HK3 × SG&A_Rate]
    I --> J[计算附加费用<br/>SAP/Logistics/Consign 基于 HK3]
    J --> K[计算 Interest = VP × Rate × Days/360]
    K --> L[计算 SK2 = SK1 + 附加 + Interest]
    L --> M[计算 DB4 = (VP - SK2) / VP]
    M --> N{DB4 < -5%?}
    N -->|是| O[标记预警 🔴]
    N -->|否| P[继续]
    O --> P
    P --> Q{还有年份?}
    Q -->|是| F
    Q -->|否| R[计算汇总指标]
    R --> S[输出 Quotation Summary]
    S --> T[结束]
```
