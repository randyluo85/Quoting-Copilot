---

## 1. 目的

建立“单主题单真理源”规则，避免公式、字段、状态机在多文档重复定义后发生漂移。

---

## 2. 唯一来源矩阵

| 主题 | 唯一来源文档 | 允许引用文档 | 禁止行为 |
|------|-------------|-------------|----------|
| 核心业务契约（角色、状态流转、红黄绿规则） | `PROJECT_CONTEXT.md` | 全部文档 | 在其他文档定义冲突版本 |
| 数据库表结构/索引/约束 | `docs/数据库设计.md` | 全部文档 | 在其他文档写“新的表结构定义” |
| 工艺成本/MHR 公式 | `docs/工艺成本计算逻辑.md` | `docs/计算公式手册.md`, `docs/报价流程详解.md` | 在引用文档改写口径 |
| NRE 投资分摊公式 | `docs/NRE投资成本计算逻辑.md` | `docs/计算公式手册.md`, `docs/报价汇总计算逻辑.md` | 在引用文档新增分摊口径 |
| QS 成本堆叠与利润指标 | `docs/报价汇总计算逻辑.md` | `docs/计算公式手册.md`, `docs/报价流程详解.md` | 在引用文档更改费用基数（HK3/VP） |
| Business Case 多年模型 | `docs/商业案例计算逻辑.md` | `docs/计算公式手册.md`, `docs/产品需求文档.md` | 在引用文档定义平行公式 |
| Payback 规则 | `docs/投资回收期计算逻辑.md` | `docs/计算公式手册.md`, `docs/报价流程详解.md` | 使用非静态回收期口径且未说明 |
| 向量检索/阈值/汇集字段 | `docs/向量设计.md` | `PROJECT_CONTEXT.md`, `docs/报价流程详解.md` | 在其他文档修改阈值标准 |
| 术语定义 | `docs/术语表.md` | 全部文档 | 同一术语在他处给不同定义 |

---

## 3. 引用规范

1. 非唯一来源文档只允许“摘要 + 链接到唯一来源”。
2. 引用路径统一使用现行中文文档名，不使用历史英文文件名。
3. 一旦唯一来源更新，引用文档必须在同一次变更中同步。

---

## 4. 变更联动清单

| 当你修改 | 必须同步修改 |
|---------|--------------|
| `PROJECT_CONTEXT.md` 中公式或状态机 | `docs/计算公式手册.md`, `docs/报价流程详解.md`, `docs/产品需求文档.md` |
| `docs/数据库设计.md` 字段/索引 | `PROJECT_CONTEXT.md`（关键字段映射）, `docs/产品需求文档.md`（前端契约段） |
| `docs/工艺成本计算逻辑.md` | `docs/计算公式手册.md`, `docs/报价流程详解.md`, `docs/术语表.md` |
| `docs/报价汇总计算逻辑.md` | `docs/计算公式手册.md`, `docs/商业案例计算逻辑.md`, `docs/术语表.md` |
| `docs/向量设计.md` | `PROJECT_CONTEXT.md`, `docs/报价流程详解.md`, `docs/术语表.md` |

## 5. 快速检查命令

```bash
# 检查旧英文文件名引用
rg -n "DATABASE_DESIGN\\.md|PROCESS_COST_LOGIC\\.md|BUSINESS_CASE_LOGIC\\.md|API_REFERENCE\\.md|PRD\\.md|GLOSSARY\\.md" docs PROJECT_CONTEXT.md

# 检查工艺成本是否仍有“人工双计”残留
rg -n "MHR_std \\+ Labor_std|MHR \\+ 人工|MHR_var \\+ Labor|Personnel \\* LaborRate" docs PROJECT_CONTEXT.md

# 检查状态机是否出现非法状态名
rg -n "vm_calculation|controlling_review" docs PROJECT_CONTEXT.md
```
